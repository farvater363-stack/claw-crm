One-off import of the old `Рассчеты.xlsx` into Claw CRM.
`TWENTY_API_URL=... TWENTY_API_KEY=... python import-excel.py <path-to-xlsx> [--dry-run]` (needs `openpyxl`).
Never commit the xlsx: it contains customer names and phone numbers.
Historical orders import as CLOSED (PRODUCTION if the installation deadline is in the future); the workbook has no status column, so the admin adjusts them.
`normalize-phones.py`: one-off rewrite of order phones to `+998XXXXXXXXX` (same env vars, `--dry-run` prints the changes only).
`setup-owner-dashboard.py`: once per workspace after `yarn twenty apply`, creates the «Сегодня» dashboard record, or renames the one made as «Аналитика», and its sidebar item (admins only, and the admin's landing page); rerunning changes nothing. Dry by default (prints the server and the plan), writes only with `--apply`: `TWENTY_API_URL=https://crm.example.com TWENTY_API_KEY=<key> python3 scripts/setup-owner-dashboard.py --apply`. It stops without writing when more than one record could be that dashboard, or on an argument it does not know. `--check` runs the script's own checks and touches nothing.
`masters-to-pay-rules.move.ts`: one-off move after the pay rules are applied: each worker with a rate per m² gets the «Мастер» category and a pay rule with that rate; rerunning changes nothing. Dry by default (prints the plan), writes only with `MOVE=apply`: `TWENTY_API_URL=... TWENTY_API_KEY=... MOVE=apply yarn vitest run --config vitest.move.config.ts scripts/masters-to-pay-rules.move.ts`.
`delete-all-orders.move.ts`: one-off move before the old statuses are removed: deletes every order (all are test data) with its payments, accruals, positions, service lines, material lines and stock movements, orders first, then recalculates the warehouse. A soft delete: the rows stay and the printed ids restore them; rows deleted earlier are counted and left as they are. Workers, pay rules, fixed accruals, clients, grilles, materials and stock movements without an order are not touched; payouts to workers are kept unless `MOVE_PAYOUTS=delete`. Dry by default (prints the server, the counts and the order); deletes only with `MOVE=apply` and `CONFIRM_DELETE_ALL_ORDERS` equal to the host name of `TWENTY_API_URL`: `TWENTY_API_URL=https://crm.example.com TWENTY_API_KEY=<key> MOVE=apply CONFIRM_DELETE_ALL_ORDERS=crm.example.com yarn vitest run --config vitest.move.config.ts scripts/delete-all-orders.move.ts`. Always name the file. If a run stops, run the same command again.
